# Word frequency lists

`freq-<lang>.txt`: the 10,000 most frequent word forms per learning language, most frequent first, one per line.
Used by `src/import.ts` to skip words that are too common for the learner's level.

Source: [hermitdave/FrequencyWords](https://github.com/hermitdave/FrequencyWords) (2018, OpenSubtitles),
licensed CC BY-SA 4.0.
